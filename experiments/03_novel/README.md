# 实验 03：自选网站爬取一篇章节超过 10 章的小说

## 实验内容

用 `requests` + `PyQuery` 爬取网络小说的多个章节。包含三组递进实验：

1. **剑来**：复现课堂模板，分别完成单章爬取与目录页解析爬取 10 章。
2. **极品家丁（JS 动态渲染分析）**：更换目标站点后出现"请求成功却抓不到数据"，定位为 JS 动态渲染导致。
3. **极品家丁（URL 规律优化）**：分析章节 URL 的数字递增规律，直接构造 URL 批量爬取，作为目录页解析方式的补充。

## 文件说明

| 文件 | 作用 |
|---|---|
| `剑来单章爬取.py` | 剑来单章爬取（验证流程） |
| `剑来十章爬取.py` | 剑来 10 章爬取（目录页解析方式，2 秒间隔） |
| `实验二爬取极品家丁js.py` | 极品家丁 JS 动态渲染问题分析 |
| `极品家丁爬取单章.py` | 极品家丁单章爬取 |
| `爬取前十章极品家丁用数字规律.py` | 极品家丁 10 章爬取（URL 数字规律构造） |
| `report/刘浩宇小说爬取实验报告定稿.docx` | 实验报告（最终版） |
| `screenshots/豆瓣小说数据采集.bmp` | 采集截图 |
| `screenshots/小说排行榜数据采集.bmp` | 采集截图 |

## 运行方式

```bash
pip install requests pyquery
python 剑来十章爬取.py
```

各脚本独立运行，输出的 txt 结果文件保存在当前目录（本仓库未附带 txt 结果，可自行运行生成）。

## 说明

- 目标站点可能已变更，运行时若请求失败需自行更换可用的小说站点。
- 报告中涉及的 `剑来.txt`、`极品家丁.txt` 等爬取结果文本未纳入仓库（体积较大且可重跑生成）。
