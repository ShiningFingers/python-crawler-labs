# 实验 05 学习笔记：turtle 绘制奥运五环

## 这个实验在做什么

用 Python 内置的 `turtle` 库画奥运五环（蓝、黑、红、黄、绿），并在下方写上名字。对应课程里的"Python 基础"——熟悉 turtle 的画笔控制和坐标。

**5 分钟看懂**：turtle 像一支会画画的笔。你告诉它"抬笔、移动到某个坐标、落笔、画圆、换颜色"，它就在窗口里画出来。奥运五环就是 5 个不同颜色、不同位置的圆。

## 前置知识与核心原理

### turtle 的核心概念

- **画笔（turtle）**：默认在窗口中心 (0,0)，朝右。
- **坐标系统**：窗口中心是原点 (0,0)，x 向右为正，y 向上为正。
- **抬笔/落笔**：`penup()` 抬笔（移动不画线），`pendown()` 落笔（移动画线）。
- **移动**：`goto(x, y)` 直接跳到坐标，`forward(n)` 沿当前方向走 n 像素。
- **画圆**：`circle(r)` 画半径为 r 的圆。
- **颜色**：`pencolor(color)` 设画笔颜色。

### 为什么要 penup + goto + pendown

如果不抬笔直接 `goto`，笔会从当前位置画一条线到目标位置。画五环时，每个环的起点不同，所以要先抬笔移过去，再落笔画圆。

## 代码逐段拆解

### 1. 初始化窗口

```python
turtle.title("奥运五环 - 刘浩宇")
turtle.bgcolor("white")
turtle.pensize(8)
turtle.speed(5)
```

`pensize(8)` 把画笔调粗，这样五环的线条明显。`speed(5)` 控制绘画速度（1-10，数字越快）。

### 2. 画五个环

```python
# 蓝色环
turtle.pencolor("blue")
turtle.penup()
turtle.goto(-110, 0)
turtle.pendown()
turtle.circle(50)
```

每个环的套路一样：选颜色 → 抬笔 → 移到圆心位置 → 落笔 → 画半径 50 的圆。五个环的 x 坐标分别是 -110、0、110（上排三个）和 -55、55（下排两个，y=-50），这样交错排列成奥运五环的样子。

### 3. 写名字

```python
turtle.penup()
turtle.goto(0, -130)
turtle.pendown()
turtle.write("刘浩宇", align="center", font=("微软雅黑", 24, "bold"))
```

`turtle.write` 可以在当前位置写文字，`align="center"` 居中，`font` 指定字体、字号、粗细。

### 4. 结束

```python
turtle.hideturtle()
turtle.done()
```

`hideturtle()` 隐藏画笔箭头，`done()` 保持窗口不关闭（否则画完窗口就闪一下没了）。

## 跑起来

### 环境依赖

`turtle` 是 Python 标准库，**不用装**。

```bash
python 乌龟.py
```

### 预期效果

弹出一个白色窗口，依次画出蓝、黑、红、黄、绿五个交错的圆环，最后在下方中央显示"刘浩宇"三个字。

### 常见报错排查

- **窗口闪一下就没了**：检查有没有 `turtle.done()`，没有的话画完程序就退出了。
- **中文显示方块**：`font` 里指定的字体（微软雅黑）系统里没有，换成系统有的中文字体。
- **`TclError`**：通常是缺少图形显示环境（比如纯命令行 Linux 服务器），本地桌面环境一般没问题。

## 踩坑与经验小结

1. **移动前先 `penup()`**，否则会留下多余的连线。
2. **记得 `turtle.done()`**，不然窗口画完就关。
3. **坐标要算清楚**：五环的位置是固定搭配，改一个其他的也要跟着调。
4. **`pensize` 调大一点**，太细的话五环不好看。
