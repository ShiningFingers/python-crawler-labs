# 实验 05：小试牛刀——turtle 的使用

## 实验内容

用 Python 内置 `turtle` 库绘制奥运五环图案。

## 文件说明

| 文件 | 作用 |
|---|---|
| `乌龟.py` | turtle 主程序，绘制蓝、黑、红、黄、绿五环，并署名 |
| `ring.png` | 截图（**存疑：无法确认此图是否为乌龟.py 的运行输出，截图待补**） |

## 运行方式

```bash
# turtle 是 Python 标准库，无需安装
python 乌龟.py
```

运行后会弹出绘图窗口，自动绘制奥运五环，完成后可关闭窗口。
