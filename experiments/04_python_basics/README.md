# 实验 04：Python 程序设计基础实验——学生成绩管理系统

## 实验内容

用 Python 内置 `tkinter` 实现一个学生成绩管理系统桌面应用，支持数据增删改查、排序、CSV 导入导出、演示数据。零第三方依赖，单文件可运行。

## 功能清单

- 添加数据：录入学号、姓名、三科成绩，自动计算总分与平均分
- 查询数据：学号精确查询 + 姓名模糊查询，命中行高亮并自动回填
- 修改数据：选中行 → 回填 → 提交更新
- 删除数据：选中单行 → 二次确认 → 移除
- 排序功能：按总分/平均分/各科成绩升序或降序
- CSV 导入导出（拓展功能）
- 一键填充演示数据

## 文件说明

| 文件 | 作用 |
|---|---|
| `student_system.py` | 学生成绩管理系统主程序（单文件，约 32KB） |
| `Tkinter.py` | tkinter 基础演示（显示文字与图片），是主程序的前置练习 |
| `students.csv` | 示例数据 |
| `report/刘浩宇python实验报告.docx` | 实验报告 |

## 运行方式

```bash
# tkinter 是 Python 标准库，无需安装
python student_system.py
```

运行后会弹出 GUI 窗口，可直接操作增删改查。

## 说明

- 代码采用分层设计：全局配置 → 工具校验 → 数据访问 → 界面搭建 → 事件处理 → 拓展功能，详见 `student_system.py` 头部注释。
- `students.csv` 可通过程序内的"保存到 CSV"功能生成，也可作为初始数据加载。
