# 实验 02 学习笔记：蜗牛笔记（woniuxy）文章爬虫

## 这个实验在做什么

用 `requests` + `PyQuery` 爬取蜗牛学苑（woniuxy.com）的笔记文章列表和详情页，把每篇文章的标题、类型、日期、阅读数、正文、图片链接提取出来，存到一个 txt 文件里。对应课程里的"静态网页爬取"——requests 发请求拿 HTML，再用 CSS 选择器从 HTML 里抠数据。

**5 分钟看懂**：你在浏览器里看到的网页，本质上是一堆 HTML 文本。爬虫的工作就是：①用代码下载这份 HTML；②用"选择器"像用 CSS 美化页面一样，精确指出"我要这个标签里的文字"；③把文字存下来。本实验的目标网站 woniuxy.com 是静态页面（内容直接写在 HTML 里，不靠 JS 渲染），所以 requests 就能搞定，不需要 Selenium。

## 前置知识与核心原理

### HTTP 请求与响应

你在浏览器输入网址，浏览器会向服务器发一个 **HTTP 请求**，服务器返回一个 **HTTP 响应**，响应里就包含了网页的 HTML。`requests.get(url)` 就是用代码发这个请求。

- **状态码**：响应开头的数字。`200` 表示成功，`404` 表示页面不存在，`403` 表示被服务器拒绝（常见于反爬）。
- **请求头 User-Agent**：告诉服务器"我是哪种浏览器"。如果不带，服务器可能知道你是程序而不是真人，直接拒绝。所以爬虫一般要伪装成 Chrome。

### HTML 结构与 CSS 选择器

HTML 是一堆嵌套的标签，比如 `<div class="title">文章标题</div>`。CSS 选择器就是一套"点名"语法：

- `.active-title`：选 class 叫 `active-title` 的元素
- `#content`：选 id 叫 `content` 的元素
- `.content-area img`：选 class 为 content-area 的元素里面所有的 img

PyQuery 就是让你用这套语法从 HTML 里取元素的库。

### 为什么本实验不用 Selenium

woniuxy.com 的文章内容直接写在 HTML 源码里（静态页面），`requests` 拿到 HTML 就能直接解析。只有当内容靠 JS 动态生成时，才需要 Selenium。能用 requests 就别用 Selenium——requests 快、省资源。

## 代码逐段拆解

### 1. 发请求 + 伪装浏览器

```python
HEADERS = {
    'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 ...'
}
resp = requests.get(url, headers=HEADERS)
resp.encoding = 'utf-8'
```

`HEADERS` 里的 `User-Agent` 让服务器以为你是 Chrome 浏览器。`resp.encoding = 'utf-8'` 指定编码，防止中文乱码。

### 2. 解析列表页

```python
for item in doc('.active-one').items():
    href = item.parent().attr('href')
    articles.append({
        'title': item('.active-title').text().strip(),
        'type' : item('.active-detail').text().strip(),
        'date' : item('.active-time').text().strip(),
        'cover': item('img').attr('src') or '',
        'url'  : BASE + href
    })
```

`doc('.active-one')` 选出所有 class 为 `active-one` 的块，每一块是一篇文章的卡片。从卡片里再用子选择器取标题、类型、日期、封面图。`item.parent().attr('href')` 拿到文章链接（链接在卡片的父元素上）。

注意 `seen` 集合去重——同一个列表页里可能有重复的文章入口，用集合记录已见过的 href，跳过重复。

### 3. 解析详情页

```python
content = doc('.content-area').text().strip()
imgs = [img.attr('src') for img in doc('.content-area img').items() if img.attr('src')]
```

详情页的正文在 class 为 `content-area` 的元素里。图片也限定在 `content-area` 内部取，避免抓到网站 logo、验证码图之类的无关图片。

### 4. 分页 + 控制频率

```python
for page in range(1, 3):
    url = f'{BASE}/note/page-{page}'
    ...
    time.sleep(1)
```

列表页的 URL 规律是 `/note/page-1`、`/note/page-2`……用循环拼 URL。`time.sleep(1)` 每篇文章间隔 1 秒，别给服务器太大压力，也降低被封的风险。

### 5. 存文件

```python
with open('woniunote.txt', 'w+', encoding='utf-8') as f:
    for art in all_data:
        f.write(f'标题：{art["title"]}\n')
        ...
```

`'w+'` 是覆盖写入（文件已存在就清空重写）。每篇文章之间用 60 个 `-` 分隔，方便阅读。

### 常见报错排查

- **`ConnectionError` / 超时**：网站可能挂了或网络不通，换个时间再试。
- **中文乱码**：检查 `resp.encoding` 是否设对（本实验是 utf-8）。
- **抓到的文章数为 0**：网站改版了，选择器对不上，需要重新分析 HTML 结构改选择器。

## 踩坑与经验小结

1. **一定要加 User-Agent**，否则很多网站直接返回 403 或空页面。
2. **列表页可能有重复入口**，用集合去重，别爬两遍。
3. **取图片要限定范围**（`.content-area img` 而不是全局 `img`），否则会抓到一堆无关图。
4. **控制请求频率**，`time.sleep` 是基本礼貌，也是自保。
5. **先打印前 100 字验证**，确认解析到的是正文而不是广告或导航。
